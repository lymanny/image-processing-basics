This repository contains beginner-friendly examples of fundamental **Image Processing** techniques using **Python, OpenCV, NumPy, and Matplotlib**.

The lessons follow a step-by-step learning path from understanding pixels to image transformations, filtering, edge detection, and morphology.

## 📚 Topics

### 1. 🖼️ Image Representation

Learn how images are represented as pixel values.

Topics:

- Read and display images
- Image shape
- Image data type
- Image channels
- BGR and RGB
- Pixel access
- Pixel modification

### 2. 🎛️ Pixel Operations

Learn how to modify pixel values.

Topics:

- Grayscale conversion
- Brightness and contrast
- Pixel arithmetic
- Image inversion
- Thresholding

### 3. 🎨 Color Spaces

Learn different ways to represent image colors.

Topics:

- RGB / BGR
- HSV
- Lab
- Per-channel adjustment
- Color range masking

### 4. 📐 Geometric Transformations

Learn how to change the size, position, and orientation of images.

Topics:

- Resize and Interpolation
- Translation
- Rotation
- Flip
- Crop
- Random Crop
- Application to Medical Images

### 5. 🧹 Filtering

Learn how to smooth images, remove noise, and enhance image details.

Topics:

- Average Blur
- Gaussian Blur
- Median Filter
- Noise Removal
- Sharpening
- Unsharp Masking

### 6. 🧭 Edge Detection

Learn how to detect edges and object boundaries.

Topics:

- Sobel X and Y
- Laplacian
- Canny Edge Detection
- Finding Boundaries / Contours

### 7. 🧩 Morphology

Learn how to modify shapes in binary images and analyze image brightness.

Topics:

- Dilation → Expand white areas
- Erosion → Shrink white areas
- Opening → Remove small white noise
- Closing → Fill small black holes or gaps
- Histogram
- Histogram Equalization
- Image Blending

## 🛠️ Libraries Used

- Python
- OpenCV
- NumPy
- Matplotlib
